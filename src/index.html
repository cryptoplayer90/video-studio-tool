开始你的视频创作
  1. 填写 API 地址和 Key，刷新模型或使用本地预设。
  2. 选择品牌与模型，填写提示词或导入批量任务。
  3. 能力未知的配置默认置灰；勾选“自定义配置”可以尝试，最终由服务端校验。
  4. 确认请求后提交。在任务卡片中停止／继续查询，完成后预览或下载。
内置模型与时长预设为 2026-10-29 快照。图片／视频的上游本地文件兼容性尚未逐模型验证，需启用自定义配置使用；默认字段为 input_reference / reference_videos，可通过兼容服务配置修改。
每轮自动查询最多 30 分钟，单次查询超时 30 秒，异常即暂停。继续查询仅查询原任务，不重新生成。浏览器直连受目标服务 CORS 限制，本工具不做代理绕过。每文件 200 MiB、每任务素材合计 500 MiB 为工具安全上限，不代表模型上限。
